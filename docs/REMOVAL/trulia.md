# Trulia

## Who actually controls these photos

Trulia is part of Zillow Group. For some homes, it receives data directly from the MLS. Trulia says those
updates must be made in the MLS by the listing agent. Check Trulia separately after requesting changes on
Zillow. See [Trulia's explanation of its data sources](https://www.trulia.com/guides/data-changes/).

## Steps

1. Open the Trulia page: {{listingLink}}
2. Ask the listing agent or brokerage to update the source photos, including the MLS when it supplies the
   listing. For a rental, contact the landlord or property manager who posted it.
3. Check the Trulia page again after the source updates. If photos remain, use Trulia's help center
   (<https://support.trulia.com>) and ask for the photos to be removed
   from the off-market listing, with the link.
