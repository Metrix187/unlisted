# Trulia

## Who actually controls these photos

Trulia is part of Zillow Group and runs on the same listing data, photos included. Getting them off Zillow
(especially through Owner View) usually takes them off Trulia too. The listing brokerage is still the
original source.

## Steps

1. Do the Zillow card first. It's the same photos.
2. Give it a few days, then check Trulia again: {{listingLink}}
3. Still there? Use Trulia's help center (<https://support.trulia.com>) and ask for the photos to be removed
   from the off-market listing, with the link.
